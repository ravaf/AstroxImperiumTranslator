<text size="20" align="left" color="#FFFFFF">
	Below will explain the basics of how the help files are parsed, and what <tags> can be used to style the information displayed. The format is much like HTML and very basic. This makes it easy to understand and quick to use.
</text>

<image src="images/hbar_1.png" align="stretch" width="500" height="10">

// TEXT BLOCK-----------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="300">
		<b>TEXT</b>
		To display some simple text, you can use this command. If the text is inside a horizontal row, the horizontal tag will control if the text stretches with the window, or is fixed.
		Size: How big the text is.
		Align: left, center or right.
		Color: The hex color for the text displayed.
		*Width: Will control the width of the text box if not inside a horizontal tag.
		*Height: Will control the height of the text box if not inside a horizontal tag.
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="300">
		**<text size="20" align="left" color="#FFFFFF">To display some simple text, you can use this command.
	</text>
</horizontal>

// IMAGE BLOCK --------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="140">
		<b>IMAGE</b>
		To display an image.
		Align: left, center, right or stretch.
		Width: Will control the width of the image.
		Height: Will control the height of the image.
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="140">
		**<image src="images/astrox_logo_1.png" align="right" width="100" height="100">
	</text>
</horizontal>

// BUTTON BLOCK --------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="200">
		<b>BUTTON</b>
		To display an button with a link.
		Align: left, center, right.
		Width: Will control the width of the image.
		Height: Will control the height of the image.
		Label: The text on the button.
		Size: size of the text on the button.
		Color: The hex color for the text displayed.
		Onclick: What to do when clicking a button.
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		**<button image="images/btn_small_1.png" width="250" height="100" align="left" label="Button Left" size="30" color="#00FFFF" onclick="mode">
	</text>
</horizontal>

// HORIZONTAL BLOCK--------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="200">
		<b>HORIZONTAL ROW</b>
		make a horizontal row. This row can be fixed or stretched. When fixed, the row will not shift when the window is resized. When stretch is applied, the row will shift the text contents based on the window size.
		Align: left, center, right.
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		**<horizontal align="fixed">
		**    ..this stuff will stay in a fixed position regardless of window size..
		**</horizontal>
		
		**<horizontal align="stretch">
		**    ..this stuff will strech with window size..
		**</horizontal>
	</text>
</horizontal>

// COMMENT BLOCK--------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="200">
		<b>COMMENTS</b>
		You can use comments using double slash. Anything after the double slash will be ignored.
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		** // this is a comment
	</text>
</horizontal>
