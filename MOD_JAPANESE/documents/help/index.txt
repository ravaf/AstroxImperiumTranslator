// TEXT BLOCK-----------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="300">
		<b>テキスト</b>
		シンプルなテキストを表示するには、このコマンドを使用します。テキストが水平行（horizontal row）の中にある場合、horizontalタグによって、テキストをウィンドウに合わせて引き伸ばすか、固定するかが制御されます。
		Size: テキストの大きさ。
		Align: left（左）、center（中央）、right（右）。
		Color: 表示されるテキストの16進数カラーコード。
		*Width: horizontalタグ内にない場合、テキストボックスの幅を制御します。
		*Height: horizontalタグ内にない場合、テキストボックスの高さを制御します。
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="300">
		**<text size="20" align="left" color="#FFFFFF">シンプルなテキストを表示するには、このコマンドを使用します。
	</text>
</horizontal>

// IMAGE BLOCK --------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="140">
		<b>画像</b>
		画像を表示します。
		Align: left、center、right、またはstretch（引き伸ばし）。
		Width: 画像の幅を制御します。
		Height: 画像の高さを制御します。
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="140">
		**<image src="images/astrox_logo_1.png" align="right" width="100" height="100">
	</text>
</horizontal>

// BUTTON BLOCK --------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="200">
		<b>ボタン</b>
		リンク付きのボタンを表示します。
		Align: left、center、right。
		Width: 画像の幅を制御します。
		Height: 画像の高さを制御します。
		Label: ボタン上のテキスト。
		Size: ボタン上のテキストのサイズ。
		Color: 表示されるテキストの16進数カラーコード。
		Onclick: ボタンをクリックした時の動作。
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		**<button image="images/btn_small_1.png" width="250" height="100" align="left" label="Button Left" size="30" color="#00FFFF" onclick="mode">
	</text>
</horizontal>

// HORIZONTAL BLOCK--------------------
<horizontal align="fixed">
	<text size="20" align="left" color="#FFFFFF" width="400" height="200">
		<b>水平行</b>
		水平行を作成します。この行は固定（fixed）または引き伸ばし（stretch）が可能です。固定の場合、ウィンドウのサイズを変更しても行は移動しません。引き伸ばしが適用されると、ウィンドウサイズに基づいてテキストコンテンツが移動します。
		Align: left、center、right。
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		**<horizontal align="fixed">
		**    ..この要素はウィンドウサイズに関係なく固定位置に留まります..
		**</horizontal>
		
		**<horizontal align="stretch">
		**    ..この要素はウィンドウサイズに合わせて引き伸ばされます..
		**</horizontal>
	</text>
</horizontal>

// COMMENT BLOCK--------------------
<horizontal align="fixed">

		ダブルスラッシュを使用してコメントを作成できます。ダブルスラッシュ以降の記述はすべて無視されます。
	</text>
	
	<text size="20" align="left" color="#FFFFFF" width="250" height="200">
		** // これはコメントです
